## How to Install APK
1. Download `spiritual-companion-v1.0.0.apk` from the GitHub Releases tab (once built via EAS or GitHub Actions).
2. Allow installation from unknown sources on your Android device (Settings → Security).
3. Tap the downloaded APK to install and enjoy instant offline devotion.
