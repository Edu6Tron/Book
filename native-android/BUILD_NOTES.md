# Native Android Build Notes

The native Android module uses the Kotlin 2.x Compose compiler plugin pattern described in the official Compose setup guide: <https://developer.android.com/develop/ui/compose/setup-compose-dependencies-and-compiler>.

The dependency-injection structure follows Android's official Hilt guidance: <https://developer.android.com/training/dependency-injection/hilt-android>.

The repository workflow uses Gradle's maintained GitHub Actions integration for Gradle caching and execution: <https://github.com/gradle/actions>.

The workflow intentionally builds an unsigned debug APK and uploads it as an artifact. A release-signed APK or Play bundle requires an application signing key stored in GitHub Actions secrets and is not generated by the initial workflow.
