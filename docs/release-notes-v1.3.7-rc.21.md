# Spiritual Companion v1.3.7-rc.21

This release adds an original, offline **NOW / NEXT / PERSONAL PLAN** devotional focus cue to the Today dashboard. It uses only the selected city’s local Panchang estimate, current device time, and the user’s locally enabled routines to surface an active Brahma Muhurta window, prepare the Evening Prarthana near sunset, or invite a personal routine choice.

It also includes Android Baseline Profile support for faster production-style startup and documents the reference-informed product work. The included study and blueprint identify lawful architecture and experience patterns only; no third-party code, assets, or branding were copied.

## Verification

The release candidate passed local Kotlin unit tests, Android lint, debug APK assembly, and release-style APK packaging. The GitHub Actions native Android workflow also passed tests, lint, and debug APK assembly for commit `142fd44`.

## Privacy and devotional boundaries

All focus calculation remains on-device. This release adds no GPS permission, background network activity, provider auto-playback, or private-data logging. Routine timing remains a personal suggestion rather than ritual authority.
